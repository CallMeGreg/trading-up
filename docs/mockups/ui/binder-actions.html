Make Grade and Sell impossible to confuse.

The current copy row gives two same-size pills the same visual weight and stacks them six points apart. These alternatives keep the same card, values, and economy, but create a deliberate change of context before a player can sell the wrong copy or grade one by mistake.

Selected direction

Choose an intent

Grade and Sell never share a copy row, which removes the original near-target problem entirely. The switch keeps both actions discoverable, defaults to Grade, and lets a player move through several duplicates without reopening menus or reselecting a copy.
