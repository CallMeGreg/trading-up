Stage pips in the card header.

Put the situational pips where the Fire element label sits, top‑right of the card. One pip per stage — solid for stages you already own, lit for the card in your hand this pull, hollow for the ones still missing. The length of the little track tells you at a glance whether you’re holding a single, a pair, or a full three‑stage line, and the lit pip shows where this pull lands in it. The pips glow in the set’s colour, so every card in a set reads as one family.

The pip picture never changes between modes — what changes is which collection a solid pip counts. Flip the switch below to read the same lines as a Classic run (this run only), a Gauntlet Showcase, or your main‑menu Binder (everything you’ve ever owned).

Why it works

  • Same slot, more meaning. The element name was a static label; the pips answer “part of a line? which stages? does this one help?” in the exact space it used to spend on one word.
  • Learn it once, reads everywhere. The pip art is identical in Classic, Gauntlet and the Binder — only the scope of a solid pip changes, so a player never has to relearn it per mode.
  • Colour follows the set. The pips take the set’s signature colour (Emberfall = ember), so a set reads as one family even where a line’s element differs. The card’s own element still shows in the art and the ● meta gem, so nothing is lost.
  • One glance, three facts. Track length = line type, the lit pip = this pull, the solid count = how close the line is to its completed‑line bonus.

Trade‑off

The literal element word is gone. If a mode leans on element identity — type match‑ups, filters — keep a small element gem beside the pips or on the “Emberfall” meta row rather than the full label.
