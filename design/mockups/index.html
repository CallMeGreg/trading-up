How to read a card: the coloured frame + gem show rarity (slate = common, green = uncommon, blue = rare, gold/purple = ultra rare). The green number is the card's current market value. Foils get an animated holographic sheen and a ×3 value. Graded cards sit in a PSA-style slab whose grade multiplies value.
Art note: these emblems are procedurally generated from each creature's name + type (deterministic, so the app reproduces them exactly). This is the proposed v1 art direction — swappable for commissioned art later.
